# cozy-to-do
My Silly little cozy to do app so that I actually focus

Written in Python, used to learn it too. 

The aim of the app is to have a low distraction, cross platform focus app that can help for users who find themselves distracted very easily.

Mainly built for myself as I do struggle to focus and other apps have too many features which can take away from the main act of just completing a to do list.
